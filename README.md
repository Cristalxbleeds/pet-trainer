# Good Pet Bell :3

Welcome to **Good Pet Bell** ([https://pettrainer.vercel.app](https://pettrainer.vercel.app)), a real-time remote clicker and bell app designed for interactive clicker training, custom audio playback, unlockable themes, and desktop global hotkeys with zero setup required :3

---

## Features :3

* **Pet Mode (Sound Receiver):** Uses the built-in clicker sound (`goodpet.mp3`) or any custom uploaded audio file, with **0%–200% Volume Boost**, **Anti-Spam Sound Mode**, and a **1:1 real-time Web Audio scheduler** that plays every incoming ring cleanly.
* **Owner Mode (Bell Clicker):** Zero-latency touch & mouse bell button, **25ms non-blocking burst pipeline**, **Room Code History**, and **Session Combo Multipliers** (`2x`, `3x`, `5x`, `7x`, `10x`) unlocked permanently by reaching single-session ring milestones.
* **Custom Keybinds & Windows Desktop App:** Assign any keyboard key (default: `Space`) or mouse button (`Left`, `Middle`, `Right`, `M4`, `M5`). On Windows (Tauri `.exe`), hotkeys work globally inside fullscreen games and background windows, with **Always-on-Top Pinning** and **System Tray** support.
* **Rings Economy & Theme Shop:** Earn **1 Ring** per click or received ring to unlock custom themes—including **Cyber Purple**, **Strawberry Milk**, **Hatsune Miku 01**, **Transfem 🏳️‍⚧️**, **Transmasc 🏳️‍⚧️**, the **Custom Color Studio** (5-layer color wheel + hex editor with **Apply**, **Revert**, and **Saved Custom Looks**), and **Cristalxbleeds 🖤**.
* **Live Room & All-Time Stats:** Track session rings, lifetime sent/received rings, best session record, unlocked combos, and active time as Owner or Pet.

---

## Quick Guide :3

1. **Pet (Sound Receiver):**
   * Open [https://pettrainer.vercel.app](https://pettrainer.vercel.app) and select **I am the Pet (Sound Receiver)**.
   * Keep the default sound (`goodpet.mp3`) or upload a custom audio file, adjust your volume boost, enter a secret room code, and press **Enter** (or click **Start Listening**).
2. **Owner (Bell Clicker):**
   * Open [https://pettrainer.vercel.app](https://pettrainer.vercel.app) (or the Windows desktop app) and select **I am the Owner (Bell Clicker)**.
   * Enter the same room code and press **Enter** (or click **Connect to Pet**).
   * Tap **RING FOR GOOD PET**, trigger unlocked **Combos**, or use your assigned **Keybind** to ring the bell in real time :3
